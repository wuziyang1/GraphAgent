# R大类文本数据采集说明

## 负责内容

本部分对应项目要求中的“采集不少于100个类别、总量不少于3000条的R大类文本数据”。为便于后续信息抽取、知识图谱构建和可视化展示，数据整理为结构化 JSONL 格式，并以 gzip 压缩后的 base64 文本形式提交：

```text
data/r_category_texts_3000.jsonl.gz.b64
```

解码和解压后得到 `r_category_texts_3000.jsonl`，其中每一行是一条 JSON 记录：

```bash
base64 -d data/r_category_texts_3000.jsonl.gz.b64 | gzip -d > data/r_category_texts_3000.jsonl
```

## 数据规模

| 指标 | 数量 |
| --- | ---: |
| 大类 | 1 个，统一标记为 `R` |
| 类别数 | 100 个 |
| 每类文本数 | 30 条 |
| 文本总量 | 3000 条 |

该数据集覆盖人工智能、知识图谱、数据库、云计算、网络安全、智慧教育、医疗健康、智能制造、自动驾驶、可信人工智能等 100 个技术与应用主题。每个主题下包含 30 条短文本，可作为后续实体识别、属性抽取和实体关系抽取的输入数据。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| `id` | 文本唯一编号，例如 `R001_001` |
| `major_class` | 数据大类，本数据集中统一为 `R` |
| `category_id` | 类别编号，从 `R001` 到 `R100` |
| `category_name` | 类别名称，例如 `人工智能基础`、`知识图谱` |
| `title` | 文本标题 |
| `text` | 文本正文 |
| `source` | 数据来源说明，本数据集标记为 `synthetic_coursework_dataset` |

## 与后续模块的衔接

后续信息抽取模块可以先解码并解压 `data/r_category_texts_3000.jsonl.gz.b64`，然后逐行读取 `r_category_texts_3000.jsonl`，对每条文本中的 `title` 和 `text` 字段进行实体、属性和关系抽取。例如：

- 从 `category_name` 和 `text` 中抽取领域主题、技术概念、应用场景和评价指标；
- 将 `category_id` 作为类别归属信息，便于按主题构建子图；
- 将抽取得到的实体关系转换为三元组，例如“知识图谱-包含-实体”“机器学习-应用于-模型评估”等；
- 将三元组写入后端知识库，供前端图谱浏览、实体查询和关系展示使用。

## 校验结果

已对数据文件进行本地校验：

- 总记录数：3000；
- 类别数：100；
- 每个类别均包含 30 条文本；
- 所有记录均包含 `id`、`major_class`、`category_id`、`category_name`、`title`、`text`、`source` 字段；
- 所有记录的 `major_class` 均为 `R`。
